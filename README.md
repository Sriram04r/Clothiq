# Clothiq
Clothiq is a smart laundry service mobile application that allows users to schedule pickups, select laundry services, track orders in real time, manage payments, receive notifications, and manage profiles and addresses through a modern and user-friendly interface.

## services 
* Wash and Fold
* Dry Wash
* Wash and Iron
* Delivery (Fast/Free)
* Recommendations about fabric usage
